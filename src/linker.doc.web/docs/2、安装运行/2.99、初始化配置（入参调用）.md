# 2.99、初始化配置（入参调用）

## 1、使用参数初始化

:::tip[v1.7.0+]
1. 如果你使用第三方程序启动linker，可以传入参数进行初始化
2. 填写了哪些字段，哪些字段就会强制覆盖原有配置
    1. 即使是null值也会覆盖，所以，不想覆盖的就把整个key都去掉，而不是给null值
    2. key一定要双引号，标准json格式
3. 将json转为base64后传入 `linker.exe base64`
4. 数据格式
```
{
    "Client":{}, //对应client.json
    "Server":{}, //对应server.json
    "Common":{}, //对应common.json
    "Action":{}, //对应action.json
    "Tuntap":{
        "IP":"10.18.18.2",  //网卡IP
        "PrefixLength":24,  //网卡掩码
        "Name":"linker",    //网卡名
        "Running":true,     //是否运行，true则启动后自动运行网卡
        "Switch":2,         //2显示延迟，8自动连接，16禁用广播
                            //32禁用nat，128调整网卡顺序，1024TCP转代理

        "Guid":"771EF382-8718-5BC5-EBF0-A28B86142278", //网卡ID 仅windows有效

        //局域网IP列表
        "Lans":[{
            "IP":"10.18.18.1",      //路由IP
            "PrefixLength":24,      //掩码
            "MapIP":"10.18.18.1",   //真实IP
            "MapPrefixLength":24,   //掩码
            "Disabled":false,       //禁用
        }],             
        //端口转发列表
        "Forwards":[
            {
                "ListenAddr":"0.0.0.0"      //监听IP
                "ListenPort":33890          //监听端口
                "ConnectAddr":"192.168.1.1" //目标IP
                "ConnectPort":3389,         //目标端口
                "Remark":"33890 转发到 3389",//描述
            }
        ], 
        //本组网络配置
        "Lease":{
            "IP" : "10.18.18.0"     //网络号
            "PrefixLength":24,      //掩码
            "Name":"linker"         //网卡名
        },
        //FEC配置
        "FecProfile":[
            {
                "SourceSymbols":10      //源包数
                "RepairSymbols":2       //冗余包数
                "Disabled":false        //禁用
            }
        ],
        //发现服务代理
        "Discoverys":[
            {
                "Name":"mDNS"               //协议名
                                            //支持mDNS、SSDP、LLMNR、NBNS、WS-Discovery、Hikvision-SADP
                "LanIps":["192.168.1.2"]    //物理网卡
                "Disabled":false            //禁用
            }
        ], 
    }
}
```
:::
